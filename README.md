# 이룸교회 중고등부 예랑 - 스마트 사역 및 회계 관리 앱 💒

> **Emil Kowalski의 디자인 엔지니어링 철학(`emil-design-eng`)**과 **Apple HIG(`apple-design`)**, **Sonner 토스트(`ask-sonner`)** 스킬을 집약하여 제작된 고품질 모바일/웹 사역 관리 애플리케이션입니다.

---

## 🌟 주요 기능 및 화면 소개 (5대 핵심 기능)

### 1. 👦🏻 학생 심방 & 기도제목
- **학생 프로필 & 퀵 커넥트**: 양형모 학생(고3) 프로필, 전화 연결(📞), 카톡 상담(💬) 바로가기
- **최근 심방 기록 타임라인**: 날짜별 심방 유형(카톡/대면/격려) 및 상세 나눔 메모 실시간 피드
- **나의 기도제목**: 수시 대학 합격, 가족 구원 등 핵심 기도제목 카드 & 터치 시 기도 동참 카운터 상승 인터랙션
- **새 심방 기록 등록 바텀시트**: 날짜, 심방 유형, 상담 상세 내용을 기록하여 즉시 반영

### 2. 📋 이번 주 교사 회의 안건
- **확정된 회의 안건 (3건)**: 전도사님 작성 및 사전 승인된 안건 타임라인
- **승인 대기 안건 (교사 제안 건)**: 소예진 선생님의 찬양팀 토요 연습시간 변경 건 등 교사 제안 실시간 표시
- **[승인 ✓] / [반려 ✕] 인터랙션**: 전도사/관리자가 승인 시 즉시 확정 안건 번호가 부여되며 상단으로 승격
- **새 안건 제안하기 모달**: 교사 누구나 회의 안건 제안서 작성 가능

### 3. 🗓️ 예랑 스마트 스케줄러 (토요예배 사전 출결 & 대타 관리)
- **토요예배 출결 요약 통계바**: `출석 N명 | 사전 결석 N명 | 지각 N명` 실시간 산출
- **토요예배 섬김이 현황판**: 대표기도, 사회, 말씀봉독, 찬양인도 실시간 매칭
- **안내 및 긴급 대타 요청 배너**: 부재 교사 발생 시 즉각 대타 요청 알림 발송
- **나의 토요예배 불참/지각 사전 등록 폼**: 결석/지각 사유, 담당 역할, 대타 교사 지정 원스톱 등록

### 4. 📸 AI 영수증 등록 및 구글 시트 실시간 연동
- **영수증 업로드 & AI 자동 OCR 인식**: 영수증 사진 업로드 시 금액(45,000원) 및 상호명(다이소 이룸점) 자동 추출
- **시트 자동 기입 폼**: 결제일자, 상호, 지출금액, 카테고리(스카/간식비/행사비 등), 지출 담당자, 목적
- **구글 시트 즉시 등록 액션**: 등록 시 1초 만에 시트 행 추가 및 회계 장부 자동 연동

### 5. 🔒 역할별 회계 보안 & 권한 분리 시스템
- **역할 스위처**: `일반 선생님 화면` vs `전도사 & 회계쌤 화면` 실시간 전환
- **일반 선생님 모드**:
  - 예랑 부서 총 잔액: `🔒 보안 적용 중 (사역자/회계 전용)` 마스킹
  - 내가 제출한 영수증 목록 및 정산 상태(`정산완료 ✓`, `승인대기 ⏳`)만 안전하게 열람
- **전도사 & 회계쌤 모드 (관리자)**:
  - 부서 전체 실잔액(`1,842,500원`, 실시간 연동 인디케이터), 총 수입 및 총 지출 현황 잠금 해제
  - 전체 교사 영수증 상세 내역 검토
  - `구글 스프레드시트 원본 장부 열기 ↗` 버튼 클릭 시 실시간 스프레드시트 테이블 팝업

## 🎨 적용된 디자인 엔지니어링 스킬

1. **`emil-design-eng` (Emil Kowalski 인터랙션 철학)**
   - 버튼/카드 프레스 피드백: `:active { transform: scale(0.97); }` (160ms ease-out)
   - 모달/바텀시트 진입: `scale(0)` 지양, `scale(0.95)` 및 `cubic-bezier(0.23, 1, 0.32, 1)` 커스텀 곡선 사용
   - 기민한 반응 속도 (250ms 이내) 및 자연스러운 댐핑 모션
2. **`apple-design`**
   - iOS 스타일 플로팅 바텀 탭바 및 햅틱/글래스모피즘(`backdrop-filter: blur(20px)`)
   - 아이폰 다이내믹 아일랜드 & 상단 상태 표시줄
   - 우측 상단 `📱 모바일 프레임 / 💻 와이드 뷰` 토글 지원
3. **`ask-sonner`**
   - 부드러운 플로팅 토스트 피드백 (등록 성공, 승인 완료, 기도 동참, 권한 전환 알림)
4. **데이터 영속성 (`localStorage`)**
   - 모든 수정 및 추가 데이터가 브라우저에 실시간 저장되며, 우측 상단 `초기 데이터 복원` 버튼으로 언제든 초기 시안으로 리셋 가능

## 🚀 실행 방법

### 방법 1: 브라우저에서 바로 열기
[`index.html`](./index.html) 파일을 Chrome, Safari, Edge 등의 브라우저로 더블 클릭하여 즉시 실행할 수 있습니다.

### 방법 2: 로컬 웹 서버 실행 (모바일 기기 동시 테스트 가능)
터미널에서 아래 명령어를 실행합니다:

```bash
# Python 내장 웹 서버 실행 (포트 8080)
python3 -m http.server 8080
```
그 후 브라우저에서 `http://localhost:8080` 으로 접속하시면 됩니다.
같은 Wi-Fi에 연결된 스마트폰에서도 `http://<컴퓨터IP>:8080` 으로 접속하여 실제 모바일 앱처럼 조작하실 수 있습니다.
